# SWAT-Mods

Community catalog of individual mods for SWAT Game, consumed by SWAT Launcher.

- [SWAT Launcher package and publishing tutorial](TUTORIAL.md)
- [Catalog schema](CATALOG_SCHEMA.md)
- [Mod manifest template](templates/mod.json)

The launcher reads `catalog.json` from the default branch. See the tutorial before publishing an entry.
